## 1. Unusual Whales：可用的事件数据

### 1.1 经济日历 `/api/market/economic-calendar`

[KNOWN, HIGH] 来自 `get_public_api_docs` 的 OpenAPI 原文：

- path: `GET /api/market/economic-calendar`
- **parameters: `[]`（空）** —— 端点本身不接受任何 date 参数。MCP 工具 `get_market_events` 的 `min_date`/`max_date` 是**客户端过滤**。
- docs_url: https://api.unusualwhales.com/docs/operations/PublicApi.MarketController.events

真实返回（截取，2026-09-02 实调用）：

```json
{
  "data": [
    {
      "type": "report",
      "time": "2026-09-04T12:30:00Z",
      "event": "Employment Report",
      "prev": "-23000",
      "forecast": "50000",
      "reported_period": "August"
    },
    {
      "type": "report",
      "time": "2026-09-04T12:30:00Z",
      "event": "Avg Hourly Earnings, M/M%",
      "prev": "0.1%",
      "forecast": "0.2%",
      "reported_period": "August"
    },
    {
      "type": "fed-speaker",
      "time": "2026-09-03T12:30:00Z",
      "event": "Federal Reserve Governor Christopher Waller speaks at Reuters NEXT Newsmaker Interview",
      "prev": null,
      "forecast": null,
      "reported_period": null
    },
    {
      "type": "report",
      "time": "2026-09-02T18:00:00Z",
      "event": "Federal Reserve Beige Book",
      "prev": null,
      "forecast": null
    }
  ]
}
```

字段：`type`（观测到 `report` / `fed-speaker` 两种）、`time`（ISO8601 UTC，含具体时刻，8:30ET = 12:30Z）、`event`（自由文本标题）、`prev`（上期值，字符串，带 `%` 或裸数字）、`forecast`（**consensus，有！**）、`reported_period`（"August"/"July"）。

**关键限制 [COMPUTED, HIGH]：覆盖窗口只有当周。** 我用 `min_date=2026-09-02, max_date=2026-09-30` 调用，返回集与不带参数**完全相同**，最远只到 2026-09-04。也就是说这个端点给不出"这周有 CPI、下周有 FOMC"的两周视野，只能给出 T+0 到 T+2 左右。要做"本周/下周日历"必须自己落库累积，或用 FMP 兜底。

另一个坑：`prev`/`forecast` 混用百分比字符串与裸整数（`"-23000"`、`"-73300000000"`），解析要按 event 名分类。且 Fed 讲话被同时打成 `type:"report"`（Hammack/Goolsbee 那条）和 `type:"fed-speaker"`（Waller 那条）——**不能只靠 `type` 过滤 Fed 事件，必须同时对 `event` 文本做正则**。[COMPUTED, HIGH]

### 1.2 财报 `/api/earnings/premarket`、`/api/earnings/afterhours`

[KNOWN, HIGH] OpenAPI 原文：两个端点，参数均为 `date`(YYYY-MM-DD，默认上个交易日)、`limit`(默认50/最大100)、`page`(从0开始)。docs_url 分别是 `PublicApi.EarningsController.premarket` / `.afterhours`。

  "report_time": "postmarket",
  "is_s_p_500": true,
  "marketcap": "1758782247597",
  "sector": "Technology",
  "implied_move": "25.352872",

字段含义 [INFERRED, HIGH]：`implied_move`/`expected_move` 是**美元**期权隐含波动幅度（AVGO 25.35 美元 ≈ 6.9% @368），`rv_1d_last_12q` 是过去 12 季实际 1 日波动与隐含的比值（>1 表示历史上实际动得比隐含大——AVGO 1.63，即隐含被低估）、`last_1d_reactions` 是最近 4 次财报次日收益率、`eps_mean_est` vs `street_mean_est`（两个不同口径的一致预期，AVGO 2.83 vs 3.217，差异大，说明一个是 GAAP 一个是 whisper/买方口径 [GUESS, LOW]，需再验）。这一条已经足够做"mega-cap 财报周"的判断。

### 1.3 IV 期限结构 `/api/stock/{ticker}/volatility/term-structure`

[KNOWN, HIGH] 参数：`ticker`(path)、`date`(可选)。返回每个真实到期日的 ATM IV。这是**事件溢价的直接读数**，比任何日历都硬。SPY 真实样本 2026-09-02：

| expiry    | dte | ATM IV     | implied_move_% | 备注                  |
| --------- | --- | ---------- | -------------- | --------------------- |
| 09-02     | 0   | 14.67%     | 0.267%         | 0DTE                  |
| 09-03     | 1   | 12.71%     | 0.507%         |                       |
| **09-04** | 2   | **13.01%** | 0.695%         | **NFP 日，IV 抬头**   |
| 09-08     | 6   | **9.80%**  | 0.871%         | 事件过后塌陷 −3.2 vol |
| 09-11     | 9   | 11.44%     | 1.235%         |                       |
| 09-15     | 13  | 10.84%     | 1.407%         |                       |
| **09-16** | 14  | **11.62%** | 1.562%         | **FOMC 日，IV 抬头**  |
| 09-18     | 16  | 12.64%     | 1.809%         | 月度 opex             |
| 10-02     | 30  | 12.71%     | 2.481%         | 30D 基准              |

[COMPUTED, HIGH] 09-04 相对 09-03 IV 上升 30bp 而 09-08 相对 09-04 骤降 321bp，这个"驼峰 + 塌陷"就是市场为 NFP 定的价。**据此可以完全不依赖日历、纯从期限结构反推"下一个大事件在哪一天"**：找 IV 曲线的局部凸起（`iv[i] > iv[i-1]` 且 `iv[i] > iv[i+1]`）。建议两条路都走，互为交叉验证。

### 1.4 其余四个工具的结论

- `get_central_bank_rates`（`/api/market/*` 路径未在本次 docs 搜索中命中，路径待验 [GUESS, LOW]）：返回 12 家央行，每家含 `latest_rate` 与 **`next_meeting_date`**。真实值：FED latest 3.75% @2026-07-31，**next_meeting_date 2026-09-16**；ECB 2.40%，next 09-10；BOE 3.75%，next 09-17；BOJ 1.00%，next 09-18。**这是本调研里唯一能提前看到 FOMC 日期的 UW 数据源**，经济日历给不了。必用。
- `get_market_state`：只给上一交易日全市场 call/put volume+premium+PCR（2026-09-02: PCR 0.591）。与事件无关，是情绪背景。
- `get_market_seasonality`：SPY/QQQ/IWM/板块 ETF 的月度历史统计。与"今天有什么事"无关，只在月初写一句"9 月历史均值"时有用。低优先级。
- `get_trading_states`：个股停牌/复牌事件流（真实样本：ASTT halt @14:05Z）。与宏观事件无关，是盘中风控信号。不进事件日历。

## 3. JPMorgan 式情景表（真实样本）

### 3.1 CPI —— 完整表，可直接照抄格式

[KNOWN, HIGH] CNBC 2025-10-23（9 月 CPI 前，JPM Market Intelligence desk 五档）：
https://www.cnbc.com/2025/10/23/how-the-stock-market-will-react-to-the-cpi-report-friday-according-to-jpmorgan.html

| core CPI m/m | 概率 | S&P 500 预期反应 |
| ------------ | ---- | ---------------- |
| < 0.25%      | 5%   | +1.0% ~ +1.5%    |
| 0.25–0.30%   | 25%  | +0.75% ~ +1.25%  |
| 0.30–0.35%   | 35%  | 0 ~ +0.5%        |
| 0.35–0.40%   | 30%  | −0.5% ~ −1.25%   |
| > 0.40%      | 5%   | −1.5% ~ −2.25%   |

同文附带 desk 的定性叙事：_"市场已定价下周降息近 100%…若 core goods 偏鹰，需要考虑通胀还没见顶"_。**格式要点：5 档、概率求和 100%、桶以基准情形为中心且宽度 5bp、反应给区间不给点估计、外加一段"为什么"的宏观逻辑。**

第二例 [KNOWN, MED]：MarketWatch 2025-07-15 live card 同一格式，桶界为 0.32%/0.37%（>0.37% → SPX −1%~~−2%；0.32–0.37% → 0~~−1%）。说明**桶界不是固定的，是每次围绕当期 consensus 重新画的**。

### 3.2 FOMC —— 按"结果类型"分档而非数值分档

[KNOWN, HIGH] Investing.com/Yahoo 2026-07-29：
https://ca.finance.yahoo.com/news/jpmorgan-maps-fed-decision-scenarios-131614621.html

| 情景                 | 概率   | S&P 500                                     |
| -------------------- | ------ | ------------------------------------------- |
| Dovish hold          | 28%    | 至多 +1.0%                                  |
| Hawkish hold（基准） | 50%    | +0.25% ~ −0.5%                              |
| +25bp 意外加息       | 20%    | −1.5% ~ −2.0%（Nasdaq 约双倍）              |
| +50bp                | 1%     | −2% ~ −4%                                   |
| 意外降息             | (余量) | −1.0% ~ +1.5%（双向，因为会被读成"藏着雷"） |

同文给出 **"期权市场为当日定价 0.8% 的即时波动"** —— 即 desk 会把 straddle 隐含日内波动与自己的情景加权期望并列，看谁贵。这正是我们能用 §1.3 的 term-structure 复现的动作。

### 3.3 NFP

[KNOWN, MED] Investing.com 2026-08-07：JPM（Andrew Tyler 团队）给 >60k 概率 65%（"good news is bad news"，>150k 可致 SPX 近 −2%），20k–60k 概率 25%（至多 +0.8%）。完整五档我没拿到全文表，只有两档 —— 标记为**不完整**。
另有 tickmill 2026-06-03 转述：70k–100k 概率 40%，为最高概率档；markets.com 2026-06-04 同一档给 SPX +0.5%~+1%。这些是二手转述，[KNOWN, LOW–MED]。

**重要：以上所有数字都是历史事件的快照，不能拿来预测下一次 CPI。** 我们要抄的是**结构**，数字必须每次现算。

### 3.4 我们自己怎么生成情景表（不抄数字的做法）

[INFERRED, MED] 三个输入就够：

1. consensus & prior —— UW economic-calendar 的 `forecast`/`prev`。
2. 事件日隐含波动 —— UW term-structure 中事件日到期的 `implied_move_perc`（SPY 09-04 = 0.695%）。这直接给出"市场为这次数据定价的 1σ 日内幅度"。
3. 分桶 —— 以 consensus 为中心，按数据本身的报告精度取桶宽（CPI 用 0.05pp，NFP 用 40k），左右各两档，共五档。
4. 概率 —— **不要编。** 要么用历史 surprise 分布（该指标过去 24 期 actual−forecast 的经验分布），要么直接写"概率未估计"。反应幅度用 β×σ：把桶中点的 surprise 除以历史 surprise 标准差得到 z，乘上 `implied_move_perc`，再乘一个符号（CPI/NFP 目前是 "hot = bad"，符号取决于当下 Fed 反应函数，必须由 agent 从近期 Fed 讲话/定价中判断，不能写死）。

这样产出的表**每个数字都有来源**，符合"不编造"要求。

## 4. 事件 playbook 规格（给 agent 的行动表）

通用规则：

- **T-1**（前一交易日晨报）：标出"明日 X 事件"，列 consensus/prior、事件日 straddle 隐含幅度、当前 IV 相对 30D 的位置。
- **T-0**（当日晨报）：情景表 + 明确的持仓动作。
- **T+1**：只写一句 vol crush 后的结果与是否触发既有仓位管理规则。

| 事件                     | 触发                   | 拉什么数据                                                                                                                        | 简报写什么                                                                                     | 期权立场                                                                                                                                                                                                                                       |
| ------------------------ | ---------------------- | --------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **CPI / PCE**            | T-1、T-0               | UW calendar `forecast`/`prev`；SPY term-structure 事件日 `implied_move_perc`；VIX 期限（VIX 现货 vs VX1/VX2）                     | 5 档情景表 + "本次定价 X% 日内波动"                                                            | 事件前**不新开卖方 vega**（不卖跨式/宽跨/裸 put）；已有短 vega 仓位在 T-1 减半或换成 defined-risk spread；想做方向只用 defined-risk（vertical / risk reversal with wing）；**事件后**才是卖 vol 的窗口（crush 已被 09-04→09-08 −321bp 量化）。 |
| **NFP**                  | T-1、T-0               | 同上 + ADP、jobless claims 作为前瞻（UW calendar 里都有）                                                                         | "good news is bad news 与否"的判断必须显式写出，因为它决定情景表符号                           | 同 CPI。NFP 的 revision 风险更大，桶宽给足。                                                                                                                                                                                                   |
| **FOMC 决议**            | T-2 起提示，T-0        | `get_central_bank_rates.next_meeting_date`（唯一提前源）；期货隐含概率（UW 无此数据 → 需外部源或直接引用新闻）；SPX 当日 straddle | 按"结果类型"分档（见 3.2），并注明会否带 SEP/dot plot（3/6/9/12 月会有）                       | 同上，且**决议日 14:00ET 后 30 分钟内不下单**（新闻发布会二次波动）。持仓到期日避开 FOMC 当周。                                                                                                                                                |
| **Fed 主席证词 / 讲话**  | T-0                    | UW calendar `type:"fed-speaker"` **加** `event` 文本正则（因为分类不可靠）                                                        | 只在讲者是主席/副主席/理事，或 Jackson Hole/半年度证词时升级为"大事件"；地方联储行长只列不升级 | 不改变立场，只提示当日盘中波动窗口。                                                                                                                                                                                                           |
| **月度/季度 opex**       | 每月第三个周五 T-3 起  | GEX（`get_gex_levels`/`get_greek_exposure_by_expiry`）、max pain                                                                  | "本周五 X 万亿名义到期，最大 gamma 集中在 K"，opex 前 pin、opex 后 gamma 释放                  | opex 前若 dealer 长 gamma → 波动被压，卖 vol 相对安全；opex 后一周波动放大，**季度 opex（3/6/9/12）后尤甚**。到期日选择避开紧贴 opex。                                                                                                         |
| **VIX 结算**             | 每月 opex 前的周三上午 | VIX 期限结构                                                                                                                      | 一句话提示                                                                                     | 不在结算日前后新开 VIX 相关结构。                                                                                                                                                                                                              |
| **Mega-cap 财报**        | T-1、T-0               | `get_upcoming_earnings`：`implied_move`、`rv_1d_last_12q`、`last_1d_reactions`                                                    | "市场定价 ±X%，过去 12 季实际/隐含比 = R，最近 4 次反应 = […]"                                 | R>1（如 AVGO 1.63）= 历史上隐含**偏低**，不要卖它的财报 vol；R<1 才考虑卖。任何情况下 defined-risk（call/put spread、jade lizard），**绝不裸 short call**。财报后 IV crush 是既定事件，长 vega 仓位在财报前一日了结。                          |
| **国债拍卖 / refunding** | T-0                    | UW 无此数据 [COMPUTED，docs 搜索未命中]；需 Treasury 官网或 FMP                                                                   | 仅当 10Y/30Y 拍卖且近期收益率是主导变量时才提                                                  | 长久期敏感仓位（长 duration proxy、TLT 结构）当日不加仓。                                                                                                                                                                                      |

跨事件硬规则（写进 prompt）：

1. 任何"卖 vega"的建议，若目标到期日之前有 CPI/FOMC/NFP/该标的财报，必须显式说明并降档为 defined-risk。
2. 情景表里的每个数字要么有来源字段，要么标 [估算/未验证]。禁止编造概率。
3. 事件日隐含幅度必须真拉 term-structure，不用记忆值。

### 6.2 计算：从上面的数到 crack / arb

单位是唯一的坑：**WTI/Brent 报价 $/bbl，RBOB/ULSD 报价 $/gal，1 bbl = 42 gal。** 换算前先 ×42。

```
gas_bbl   = RB1! × 42
dist_bbl  = HO1! × 42
gasoline_crack  = gas_bbl  − WTI
distillate_crack = dist_bbl − WTI
crack_321 = (2 × gas_bbl + 1 × dist_bbl) / 3 − WTI
brent_wti = BRN1! − CL1!
```

3-2-1 定义引自 EIA "An introduction to crack spreads"（https://www.eia.gov/todayinenergy/detail.php?id=1630）：两桶汽油 + 一桶馏分油对三桶原油 [KNOWN, HIGH]。

[COMPUTED, HIGH] 用上面 14:11Z 的真实报价代入：

| 指标 | 值（2026-09-02T14:11Z, TradingView 前月合约） |
|---|---|
| RBOB → $/bbl | 3.1621 × 42 = **132.81** |
| ULSD → $/bbl | 4.6397 × 42 = **194.87** |
| Gasoline crack (vs WTI) | 132.81 − 89.07 = **+43.74 $/bbl** |
| Distillate crack (vs WTI) | 194.87 − 89.07 = **+105.80 $/bbl** |
| **3-2-1 crack** | (2×132.81 + 194.87)/3 − 89.07 = **+64.43 $/bbl** |
| **Brent−WTI** | 93.87 − 89.07 = **+4.80 $/bbl** |

（口径说明：这是用**前月连续合约**算的即时 crack，与炼厂实际用现货/远月算的会差；作为日度趋势指标足够，作为交易信号不够。[INFERRED, MED]）

### 6.3 交易台怎么读它做通胀判断

- **权重。** 汽油（motor fuel）在 CPI 篮子中约 **2.9%**（Purdue 农经 2026-04 引 BLS 相对重要性表）[KNOWN, MED]；能源整体（含电、天然气、取暖油）约 6–7.5% [KNOWN, LOW–MED，来源为 2022 年 Pew，权重每年重估，需以 BLS 相对重要性表 https://www.bls.gov/cpi/tables/relative-importance/home.htm 为准]。**算术含义 [COMPUTED]：零售汽油环比 ±10% ≈ headline CPI m/m ±0.29pp，而 core CPI 受影响为 0（能源被剔除）。这就是为什么 JPM 的情景表按 core 分桶——原油只驱动 headline 和 core 的"二阶传导"。**
- **传导与滞后。** 期货 RBOB → 零售汽油（GASREGW）的传导典型为 **1–3 周**，且是不对称的（涨得快跌得慢，"rockets and feathers"）[KNOWN, MED，教科书结论，未在本次调研中引到具体论文]。因此：**本月的 RBOB 走势主要影响下个月的 headline CPI，而不是本周即将发布的那份。** 简报必须把这个滞后写清楚，否则会给出错误的"CPI 前瞻"。
- **crack 的读法。** crack 走阔 = 成品油相对原油更贵。两种解读，必须区分：① **供给侧**（炼厂检修/意外停车/出口）→ 零售价上行、CPI 能源分项上行、炼厂股（VLO/PSX/MPC）受益；② **需求侧**（驾驶季/工业活动强）→ 同样推高零售价，但同时是经济强的信号，对 Fed 是"两头都鹰"。区分靠库存（EIA 周三 10:30ET 报告）与裂解的期限结构。
- **馏分油（ULSD）另有一条通道**：它主要进 **PPI / 运输成本 / core goods**，而不是 CPI 能源分项。distillate crack 极端走阔（本次 105.80 $/bbl，远高于 gasoline crack 43.74）是**核心商品通胀的上游压力信号**，这恰好呼应 §3.1 里 JPM 那句"若 core goods 偏鹰，需考虑通胀还没见顶"。[INFERRED, MED]
- **Brent−WTI arb** 主要是美国原油出口经济性与内陆管输的函数，对美国 CPI 的直接信息量最低；它宽 = 美湾出口有利可图 = 美国库存去化 = 对 WTI 偏支撑。当前 4.80 $/bbl 属于正常区间 [GUESS, LOW —— 我没有历史分布来定义"正常"，不要在简报里下这个判断，除非先落库算分位]。

### 6.4 简报每天打印什么（一到两行）

第一行（永远打）：

> **能源**：WTI 89.07（−1.27%）/ Brent 93.87（−0.82%），Brent−WTI 4.80；RBOB 3.1621、ULSD 4.6397。3-2-1 crack **64.43 $/bbl**（汽油 43.74 / 馏分 105.80）。—— TradingView 前月合约 2026-09-02T14:11Z

第二行（仅当触发时打）：

> **通胀含义**：3-2-1 crack 处于 N 日分位 P%；馏分裂解 > 汽油裂解 2.4 倍，core goods 上游成本压力偏紧。RBOB 近 4 周 ±X% → 传导至零售汽油约 1–3 周 → 主要影响**下一份** headline CPI（约 ±0.0Y pp），对本周 core CPI 无直接影响。

触发条件建议：3-2-1 crack 单日变动 > 5%、或 WTI/Brent 单日 > 3%、或 crack 落在自建历史分布的 10%/90% 分位外。分位数需要我们自己落库（UW 的 USO/BNO/UGA OHLC 500 天足够 bootstrap，期货则要自己每天存 TradingView 报价）—— **在有至少 250 个观测之前，简报里不要出现"高/低于历史"这类措辞。**

对期权立场的影响：能源只在两种情况下改变建议 —— ① 组合里有能源标的（XLE/XOP/CVX/OXY/炼厂）时，crack 是它们的核心 driver，写进个股逻辑；② headline vs core 分歧会改变 §4 情景表里"方向符号"的判断（headline 因油价冲高但 core 温和 = 市场通常忽略，Fed 也忽略）。**能源本身不构成新开仓理由。**
